## echCYD

I bought an Echelon EX-3 instead of a higher-end model to save money thinking I wouldn't mind connecting a tablet with the Echelon app, but I was wrong. Having a simple built in screen for simple biking data is essential. This project attempts to fix that.

### Features
* Current resistance setting
* Current cadence (RPM)
* Total rotations

### How to use

1. Get a "CYD" ESP32 device with 2.8 inch screen such as https://www.aliexpress.us/item/3256804785406072.html. 
1. Install the TFT_eSPI Arduino library, then replace the User_Setup.h file with the one provided.
2. Upload the sketch and bike!
